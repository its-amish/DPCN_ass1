# Extreme Bipartite Network Analysis

This directory contains the code, report, and visualizations for analyzing the ideological extremes of a cohort using a bipartite network approach. The analysis extracts strong opinions (Strongly Agree / Strongly Disagree) from survey responses to build and study a question-to-question projected network.

## Directory Structure

- **`main.ipynb`**: The primary Jupyter Notebook. It processes the raw survey data (`Survey_Results_UC.csv`), constructs the bipartite network (Students $\leftrightarrow$ Questions), projects it into a weighted Question-to-Question network ($G_Q^W$), and calculates centrality metrics (Strength, Betweenness, Eigenvector) to identify the core ideological anchors of the cohort.
- **`extreme_bipartite_report.tex` / `.pdf`**: The formal LaTeX report documenting the methodology, topological analysis, metrics, and conclusions of the network study.
- **`Survey_Results_UC.csv`**: The raw dataset containing the Likert-scale responses from the survey.
- **`extreme_plots/`**: A directory containing all the static plots and figures generated by the notebook (e.g., centrality heatmaps, degree distributions) which are used in the LaTeX report.
- **`Visualizers/`**: Contains interactive HTML visualizers for exploring the networks:
  - `bipartite_visualizer.html`: An interactive D3.js force-directed graph of the original bipartite network (Students and Questions).
  - `projected_visualizer.html`: An interactive visualization of the weighted projected $K_{60}$ network ($G_Q^W$).

## How to use

1. Run `main.ipynb` to regenerate the network analysis and update the static plots in `extreme_plots/`.
2. Compile `extreme_bipartite_report.tex` to build the PDF report.
3. Open the `.html` files in the `Visualizers/` directory in any modern web browser to interactively explore the network topologies.
